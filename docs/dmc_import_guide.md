# คู่มือการนำเข้าข้อมูลนักเรียนจากระบบ DMC (SIS Module)

ระบบ **Student Information System (SIS)** ใน School CMS Mix V2.8 รองรับการนำเข้าข้อมูลนักเรียนอย่างรวดเร็วผ่านไฟล์ CSV ที่ส่งออกจากระบบ **DMC (Data Management Center)** ของสพฐ.

## 1. การเตรียมไฟล์จากระบบ DMC
1. เข้าใช้งานระบบ DMC ของโรงเรียน
2. ไปที่เมนู **"ส่งออกข้อมูล (Export)"**
3. เลือกส่งออกข้อมูล **"รายชื่อนักเรียนรายบุคคล"**
4. บันทึกไฟล์เป็นนามสกุล **.csv (Comma delimited)**
   - *หมายเหตุ: หากไฟล์เป็น Excel (.xlsx) ให้ทำการ Save As เป็น CSV ก่อนนำเข้า*

## 2. ขั้นตอนการนำเข้าข้อมูล
1. เข้าสู่ระบบจัดการ (Admin) ของ School CMS
2. ไปที่เมนู **"ข้อมูลนักเรียน"**
3. คลิกปุ่ม **"นำเข้าข้อมูล (DMC)"** ที่มุมขวาบน
4. เลือกไฟล์ CSV ที่เตรียมไว้
5. คลิกปุ่ม **"ยืนยันการนำเข้าข้อมูล"**
6. ระบบจะทำการประมวลผล (ใช้เวลาประมาณ 10-30 วินาที ขึ้นอยู่กับจำนวนนักเรียน)

## 3. สิ่งที่ระบบดำเนินการอัตโนมัติ
- **การแปลงปี พ.ศ. เป็น ค.ศ.:** ระบบจะตรวจสอบวันที่ (วันเกิด) และแปลงจาก พ.ศ. เป็น ค.ศ. ให้โดยอัตโนมัติ
- **การตรวจสอบข้อมูลซ้ำ:** หากมี "เลขประจำตัวประชาชน" ซ้ำในระบบ ระบบจะทำการ **อัปเดต (Update)** ข้อมูลเดิมให้เป็นปัจจุบัน แทนการเพิ่มข้อมูลใหม่
- **การจัดการข้อมูลว่าง:** หากช่องใดในไฟล์ไม่มีข้อมูล (เช่น เบอร์โทรศัพท์ หรือ อาชีพ) ระบบจะบันทึกเป็นค่าว่างหรือ NULL ให้อย่างถูกต้อง
- **ความปลอดภัย:** ระบบใช้ Transaction ในการบันทึกข้อมูล หากเกิดข้อผิดพลาดระหว่างทาง ข้อมูลทั้งหมดจะไม่ถูกบันทึกเพื่อป้องกันข้อมูลไม่สมบูรณ์

## 4. โครงสร้างคอลัมน์ที่รองรับ (ตัวอย่างบางส่วน)
ระบบยึดตามลำดับคอลัมน์มาตรฐานของไฟล์ DMC ดังนี้:
- คอลัมน์ 10: รหัสนักเรียน
- คอลัมน์ 11: เลขประจำตัวประชาชน
- คอลัมน์ 13: คำนำหน้า
- คอลัมน์ 14: ชื่อตัว
- คอลัมน์ 15: ชื่อกลาง (ถ้ามี)
- คอลัมน์ 16: นามสกุล
- คอลัมน์ 18: เพศ
- ... (และคอลัมน์อื่นๆ ตามมาตรฐาน DMC)

---
*หากพบปัญหาในการนำเข้าข้อมูล กรุณาตรวจสอบว่าไฟล์ CSV มีการเข้ารหัสเป็น UTF-8 หรือ Windows-874 (Thai)*
