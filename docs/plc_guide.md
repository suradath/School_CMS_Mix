# คู่มือการใช้งานระบบ PLC (Professional Learning Community) - V2.8

ระบบชุมชนแห่งการเรียนรู้ทางวิชาชีพ (PLC) ออกแบบมาเพื่อช่วยคุณครูในการสะสมชั่วโมงเพื่อยื่นขอเลื่อนวิทยฐานะ โดยเน้นความโปร่งใสและลดภาระงานเอกสาร

## 1. การจัดการกลุ่ม PLC
- **การสร้างกลุ่ม:** ครูผู้ประสานงานสามารถสร้างกลุ่ม กำหนดเป้าหมายชั่วโมง (ค่าเริ่มต้น 50 ชม./ปี) และปีการศึกษา (พ.ศ.)
- **การเข้าร่วมกลุ่ม:** ครูคนอื่นๆ สามารถค้นหากลุ่มและกด "ขอเข้าร่วม" เพื่อให้หัวหน้ากลุ่มกดอนุมัติ
- **บทบาท:** หัวหน้ากลุ่ม (Head) มีสิทธิ์ในการอนุมัติชั่วโมงและจัดการสมาชิก ส่วนสมาชิก (Member) มีสิทธิ์บันทึกกิจกรรมและแลกเปลี่ยนสื่อ

## 2. การบันทึกกิจกรรม (Meeting Log)
- ทุกครั้งที่สิ้นสุดการประชุม PLC ให้สมาชิกหรือหัวหน้ากลุ่มทำการบันทึกข้อมูล:
    - วันที่และเวลา
    - หัวข้อกิจกรรม / ประเด็นปัญหา
    - แนวทางการแก้ไข / ผลการดำเนินการ
    - จำนวนชั่วโมงที่ใช้จริง
    - อัปโหลดสื่อการสอนหรือภาพประกอบ (PDF, Word, PPT, Image)

## 3. ระบบอนุมัติชั่วโมง (Verification)
- ชั่วโมงที่บันทึกจะอยู่ในสถานะ "รอการตรวจสอบ"
- หัวหน้ากลุ่มหรือ Admin ต้องทำการตรวจสอบความถูกต้องก่อนกด "อนุมัติ"
- ชั่วโมงจะถูกนับสะสมเข้าหน้า Dashboard หลังจากได้รับการอนุมัติแล้วเท่านั้น

## 4. คลังสื่อการสอน (Material Library)
- สมาชิกสามารถดูและดาวน์โหลดไฟล์สื่อการสอนที่เพื่อนครูอัปโหลดไว้ในการประชุมแต่ละครั้งได้จากแท็บ "คลังสื่อการสอน" ในหน้า Workspace

## 5. การออกรายงานสรุป (Reports)
- **รายงานรายบุคคล:** ระบบเจนเนอเรตรายงานสรุปชั่วโมงในรูปแบบ A4 พร้อมช่องลงนามรับรอง (ครูผู้รายงาน, หัวหน้ากลุ่ม, ผู้อำนวยการ)
- **การส่งออก Excel:** สามารถดาวน์โหลดไฟล์สรุปชั่วโมงรายปีเป็นไฟล์ CSV/Excel ได้ทันที
- **รายงานภาพรวม:** สำหรับฝ่ายบุคคล (HR) สามารถดูสรุปชั่วโมงของครูทุกคนในโรงเรียนได้เพื่อตรวจสอบความก้าวหน้า
