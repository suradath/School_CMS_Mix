# คู่มือการติดตั้งระบบ School CMS Mix V2.9 (ภาษาไทย)

ระบบบริหารจัดการเนื้อหาโรงเรียน (School CMS Mix V2.9) พัฒนาด้วยภาษา PHP 8.1+ และฐานข้อมูล MySQL/MariaDB โดยถูกออกแบบมาให้ติดตั้งได้ง่ายผ่านระบบ Installer แบบ Step-by-step

## 📋 ข้อกำหนดของระบบ (System Requirements)

- **Language:** PHP 8.1 หรือเวอร์ชันที่สูงกว่า
- **Database:** MySQL 5.7+ หรือ MariaDB 10.4+
- **Extensions:**
  - `pdo`
  - `pdo_mysql`
  - `gd` (สำหรับการจัดการรูปภาพ)
- **Web Server:** Apache (พร้อมเปิดใช้งาน `.htaccess`) หรือ Nginx

---

## 🚀 ขั้นตอนการติดตั้ง (Installation Steps)

### 1. การเตรียมไฟล์และเซิร์ฟเวอร์
1. คัดลอกไฟล์ทั้งหมดของโปรเจกต์ไปยังโฟลเดอร์ Web Root (เช่น `public_html` หรือ `www`)
2. ตรวจสอบว่าโฟลเดอร์หลักของโปรเจกต์และโฟลเดอร์ `uploads/` สามารถเขียนไฟล์ได้ (Permission 755 หรือ 777)

### 2. การเตรียมฐานข้อมูล
1. เข้าไปที่เครื่องมือจัดการฐานข้อมูลของคุณ (เช่น phpMyAdmin)
2. สร้างฐานข้อมูลใหม่ (แนะนำให้ใช้ Collation เป็น `utf8mb4_unicode_ci`)

### 3. การใช้งานตัวติดตั้ง (Web Installer)
1. เปิด Browser แล้วไปที่ `http://your-site/install.php`
2. **Step 1 (Check):** ระบบจะตรวจสอบความพร้อมของเซิร์ฟเวอร์
3. **Step 2 (Database):** กรอกข้อมูลการเชื่อมต่อฐานข้อมูล:
   - **Host:** โดยปกติคือ `localhost`
   - **DB Name:** ชื่อฐานข้อมูลที่สร้างไว้ในข้อ 2
   - **User/Pass:** ชื่อผู้ใช้และรหัสผ่านของฐานข้อมูล
4. **Step 3 (Finalize):** ตั้งชื่อเว็บไซต์/โรงเรียน และสร้างบัญชีผู้ดูแลระบบ (Admin)
   - ข้อมูลนี้จะถูกใช้เพื่อเข้าสู่ระบบการจัดการหลังบ้าน

### 4. หลังการติดตั้ง
1. ระบบจะสร้างไฟล์ `config.php` ให้อัตโนมัติ
2. **ข้อแนะนำ:** เพื่อความปลอดภัย กรุณาลบไฟล์ `install.php` ออกจากเซิร์ฟเวอร์ทันทีหลังจากติดตั้งสำเร็จ

---

## 🛠️ การตั้งค่าเพิ่มเติม (Configuration)

หากต้องการตั้งค่าความปลอดภัยของ URL ให้เป็นแบบ Clean URLs:
- **Apache:** ระบบมีไฟล์ `.htaccess` ให้แล้ว ตรวจสอบว่าเปิดใช้งาน `mod_rewrite`
- **Nginx:** กรุณาตั้งค่า `try_files` ใน config:
  ```nginx
  location / {
      try_files $uri $uri/ /index.php?$query_string;
  }
  ```

---

> [!CAUTION]
> ห้ามแชร์ไฟล์ `config.php` ให้กับผู้อื่น เนื่องจากบรรจุรหัสผ่านฐานข้อมูลที่มีความสำคัญ
